- 训练脚本：`train_p2.py`

| 配置项 | 设置 |

## 3. 结构改进

标准YOLOv8通常使用P3、P4、P5三个尺度进行检测：

```text
P3：较小目标
P4：中等目标
P5：较大目标
```

P2模型额外增加一个更高分辨率的检测层：

```text
P2：更小目标
```

因此，模型可以在更细粒度的特征图上预测目标框，理论上更适合检测小目标。

## 4. 原理说明

目标检测中，小目标在深层特征图上可能只占很少像素，经过多次下采样后细节容易丢失。例如远处学生手部、手机、头部姿态等，都可能在低分辨率特征图上表现不明显。

P2检测头的原理是：

1. 保留更浅层、更高分辨率的特征。
2. 将该特征加入Neck和Detect Head。
3. 让模型在更细的网格上预测小目标。

简化理解：

```text
普通YOLOv8：P3 + P4 + P5
P2模型：P2 + P3 + P4 + P5
```

## 5. 为什么用于课堂行为检测

课堂图像通常具有以下特点：

- 一张图中学生数量多。
- 部分学生距离摄像头远。
- 手机、手部、头部姿态等区域较小。
- 举手和使用手机等行为依赖细节。

因此，增加P2检测头在理论上有助于改善小目标检测。

## 6. 特点

优点：

- 更关注小目标。
- 理论上可提升远距离学生行为检测。
- 对手部、手机等细节区域更友好。

不足：

- 新增检测头随机初始化，训练难度增加。
- 检测分支变多，计算量和显存占用上升。
- batch size从8降到4，训练稳定性可能下降。
- 如果标注质量或数据量不足，P2分支难以学到稳定规律。

## 7. 实验结论

P2模型没有超过baseline，说明当前问题不是单靠增加小目标检测分支就能解决。

可能原因包括：

- 新增P2分支缺少预训练权重。
- 课堂行为类别依赖姿态和上下文，不只是目标尺寸问题。
- 数据集中小目标标注质量会限制P2收益。
- batch size降低导致训练噪声增加。

论文中可将其作为小目标结构改进实验，说明“理论上适合小目标”的结构并不一定在当前数据集上直接有效。
