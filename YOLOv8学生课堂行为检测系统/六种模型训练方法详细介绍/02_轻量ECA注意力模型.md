## 3. 结构改进

该模型在YOLOv8m的部分特征层后加入ECA注意力模块。ECA全称为Efficient Channel Attention，是一种轻量通道注意力机制。

普通卷积特征图可以表示为：

```text
C x H x W
```

其中：

- `C`表示通道数。
- `H`和`W`表示特征图空间尺寸。

ECA关注的是不同通道的重要性。它通过全局池化获得每个通道的统计信息，再使用轻量的一维卷积建模相邻通道之间的关系，最后生成通道权重，对原特征进行重新加权。

## 4. 原理说明

ECA的基本流程：

1. 对输入特征图做全局平均池化，得到每个通道的全局响应。
2. 使用一维卷积捕获局部跨通道交互。
3. 使用Sigmoid生成通道注意力权重。
4. 将权重乘回原特征图，使重要通道增强，不重要通道减弱。

简化理解：

```text
输入特征 -> 统计每个通道重要性 -> 生成通道权重 -> 重新加权特征
```

## 5. 为什么用于课堂行为检测

课堂行为检测中，不同行为可能依赖不同视觉线索：

- 举手依赖手臂区域特征。
- 使用手机依赖手部和小物体特征。
- 低头和趴桌依赖头部、肩部、桌面关系。

ECA的目标是让模型自动突出更有用的通道特征，从而增强行为识别能力。

## 6. 特点

优点：

- 参数量小，计算开销低。
- 比SE等注意力模块更轻量。
- 理论上可以增强关键通道特征。

不足：

- 新增注意力层是随机初始化的。
- 插入模块会改变原YOLOv8m特征分布。
- 数据集规模有限时，注意力权重可能学不稳定。
- 实验结果没有超过baseline。

## 7. 实验结论

该方法说明：注意力机制并不是只要加入就一定提升。对于当前课堂行为数据集，baseline已经具有较强特征表达能力，简单加入轻量ECA没有带来有效收益。

论文中可将其作为结构改进对比实验，用于说明模型优化需要结合数据规模和训练稳定性，而不能单纯堆叠模块。
