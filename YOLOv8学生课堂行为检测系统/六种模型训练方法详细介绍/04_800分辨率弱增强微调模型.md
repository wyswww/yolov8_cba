# 04 800分辨率弱增强微调模型

## 1. 对应文件

- 训练脚本：`train_finetune_img800.py`
- 输出目录：`runs/detect/baseline_finetune_img800_weakaug`
- 初始权重：`runs/detect/baseline_mAP_100epochs/weights/best.pt`
- 模型结构：标准YOLOv8m，不修改网络结构

## 2. 训练配置

| 配置项 | 设置 |
|---|---|
| 初始权重 | baseline最优权重 `best.pt` |
| 训练轮数 | `epochs=50` |
| 早停 | `patience=20` |
| 输入尺寸 | `imgsz=800` |
| batch size | `batch=4` |
| 优化器 | `AdamW` |
| 初始学习率 | `lr0=0.0001` |
| 学习率策略 | `cos_lr=True` |
| warmup | `warmup_epochs=2.0` |
| 损失权重 | `box=7.5, cls=0.65, dfl=1.5` |

## 3. 弱增强策略

该模型关闭了强增强：

```python
mosaic=0.0
mixup=0.0
copy_paste=0.0
close_mosaic=0
```

同时只保留轻微的几何和颜色扰动：

```python
hsv_h=0.01
hsv_s=0.3
hsv_v=0.3
degrees=3.0
translate=0.05
scale=0.15
shear=1.0
perspective=0.0
fliplr=0.5
```

## 4. 原理说明

该方法的核心是二阶段微调：

```text
第一阶段：baseline在640输入下训练，学习稳定课堂行为特征
第二阶段：加载baseline best.pt，在800输入下低学习率微调
```

相比从头训练，二阶段微调可以保留baseline已经学到的能力。相比640输入，800输入可以保留更多细节，对小目标和姿态识别更有利。

弱增强的原因是课堂行为检测强依赖真实上下文。如果使用mosaic、mixup、copy-paste等强增强，可能把不同课堂图像拼接到一起，制造不符合真实课堂关系的样本，反而破坏行为语义。

## 5. 为什么提高分类损失权重

脚本中将分类损失权重从baseline的 `cls=0.5` 提高到 `cls=0.65`。

原因是课堂行为类别之间存在相似性：

- 阅读和书写都可能表现为低头。
- 低头和趴桌都与头部姿态相关。
- 使用手机有时与普通低头动作相似。

提高分类损失权重可以让模型更关注类别区分。

## 6. 特点

优点：

- 不改网络结构，风险比结构改进小。
- 从baseline最优权重出发，训练更稳定。
- 800输入有助于小目标和细节。
- 弱增强更符合真实课堂场景。

不足：

- 显存和推理开销高于640输入。
- batch size下降到4。
- 只提高分辨率和弱增强时，测试集提升不够稳定。

## 7. 实验结论

该策略是后续strong模型的重要基础。它证明训练策略优化比盲目改结构更有价值，但单独使用高分辨率弱增强还不足以充分解决类别长尾问题。

因此，最终strong模型在该策略基础上继续加入长尾均衡训练集。
