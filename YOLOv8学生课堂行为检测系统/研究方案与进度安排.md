# 一、立题依据和研究内容

## 1. 立题依据

**核心问题**：传统课堂行为观察依赖教师肉眼判断 → 主观性强、无法覆盖全班、难以量化追溯

**解决方案**：计算机视觉 + 深度学习目标检测（YOLOv8）→ 自动识别学生行为、实时量化分析

**研究意义**：
- 理论：探索注意力机制、小目标检测、类别不均衡等问题在教育场景的适用性
- 应用：将课堂表现转化为可视化数据，辅助教学管理与质量评估

**现有不足**：多数研究仅关注模型精度，缺乏完整交互系统与课堂状态分析

## 2. 研究内容

**① 数据集构建** — 6类行为（举手/阅读/书写/看手机/低头/趴桌），YOLO格式标注，训练集4202张/验证集1207张/测试集209张

**② 模型训练与评估** — YOLOv8m + COCO预训练、Precision/Recall/mAP@0.5/mAP@0.5:0.95四项指标

**③ 六种训练策略对比实验**：

| 序号 | 模型 | 核心策略 |
|:---:|------|----------|
| 1 | 基线模型 | YOLOv8m标准训练，对照组 |
| 2 | ECA注意力 | 轻量通道注意力增强特征选择 |
| 3 | P2检测头 | 增加高分辨率分支提升小目标检测 |
| 4 | 800弱增强微调 | 高分辨率 + 关闭强增强 + 二阶段微调 |
| 5 | CoordAtt+ECA v2 | 空间坐标注意力 + 通道注意力 + 弱增强匹配 |
| 6 | **Strong最终模型** | 长尾均衡 + 800分辨率 + 弱增强 + 二阶段 |

**④ 桌面端系统开发** — PyQt5 + OpenCV，支持图片/视频/摄像头/批量检测 + 结果保存

**⑤ 专注度计算** — 类别权重映射 + 置信度融合 + 视频流时序跟踪

![系统架构](论文图表/图3-1_系统总体架构图.png)

**关键结论**：CoordAtt+ECA组合注意力（方法5 v2，mAP@0.5=0.9625）和训练策略优化Strong（方法6，mAP@0.5=0.9673）均大幅超越基线；其中Strong不改网络结构仅靠训练策略融合即达最优，但CoordAtt+ECA的成功也证明了空间-通道互补注意力设计在匹配弱增强策略后同样有效

# 三、研究方案和进度安排

## 1. 研究方案

**技术路线**：数据集构建 → 基线训练 → 6种改进实验 → 系统开发 → 结果分析

## 2. 六种模型技术方案

### 方法1：YOLOv8m 基线模型（对照组）

- **结构**：标准 YOLOv8m（Backbone C2f + Neck PAN-FPN + Head 解耦头），不改任何结构
- **训练**：COCO 预训练权重 → 课堂数据集 100 轮微调，imgsz=640, batch=8, lr=5×10⁻⁴
- **增强**：完整 YOLO 增强（Mosaic 0.8, MixUp 0.1, Copy-Paste 0.05, 强 HSV/几何扰动）
- **定位**：所有改进实验的对照基准
- **选择原因**：YOLOv8m 在精度和速度之间平衡最优；需先建立可复现的强基线，后续改进才有比较意义

![baseline混淆矩阵](论文图表/六模型混淆矩阵/01_YOLOv8m_Baseline_confusion_matrix_normalized.png)

### 方法2：轻量 ECA 注意力模型

- **结构**：在 C2f 模块 Bottleneck 后嵌入 ECA 通道注意力（一维卷积建模跨通道依赖）
- **原理**：GAP → 自适应一维卷积(k=3~5) → Sigmoid → 通道加权，参数量极低
- **训练**：手动层号映射加载 yolov8m.pt 可对齐权重，新增 ECA 层随机初始化
- **定位**：验证"轻量通道注意力能否提升课堂行为检测"
- **选择原因**：课堂行为依赖不同视觉线索（举手→手臂、看手机→手持物、低头→头部姿态），通道注意力理论上能自动强化关键通道；选 ECA 而非 SE/CBAM 是因为它极轻量，几乎不增加推理延迟

![ECA混淆矩阵](论文图表/六模型混淆矩阵/02_ECA_Attention_confusion_matrix_normalized.png)

### 方法3：YOLOv8m-P2 小目标检测模型

- **结构**：在 P3/P4/P5 基础上增加 P2 检测分支（4×下采样，分辨率提升 4 倍）
- **原理**：P2 浅层高分辨率特征 → 与 P3 上采样特征拼接 → 新增 P2 解耦头
- **训练**：Backbone/Neck/原检测头权重迁移，P2 分支随机初始化，batch 降至 4
- **定位**：验证"更高分辨率特征图能否改善举手、手机等小目标检测"
- **选择原因**：课堂图像中远排学生的手机、举手手势仅占极少像素（20×20以下），P3层8×下采样后细节丢失严重；P2层保留4倍分辨率特征，理论上更适合极小目标

![P2混淆矩阵](论文图表/六模型混淆矩阵/03_P2_SmallObject_confusion_matrix_normalized.png)

### 方法4：800 分辨率弱增强二阶段微调

- **结构**：标准 YOLOv8m，**不修改网络结构**
- **训练**：第一阶段基线 best.pt → 第二阶段 imgsz=800 微调 50 轮
- **增强**：关闭 Mosaic/MixUp/Copy-Paste，仅保留弱 HSV(0.01/0.3/0.3)和轻量几何扰动(±3°)
- **损失**：cls 从 0.5 提至 0.65，增强类别区分；lr 降至 1×10⁻⁴，余弦退火
- **定位**：验证"高分辨率+保护行为语义+渐进微调"组合效果
- **选择原因**：方法2/3均失败 → 反思瓶颈不在网络结构，而在数据策略；Mosaic 把不同教室学生强行拼在一起会破坏行为空间语义，关闭强增强更贴合课堂固定场景；二阶段微调比从头训练更稳

![800弱增强混淆矩阵](论文图表/六模型混淆矩阵/04_800_WeakAug_confusion_matrix_normalized.png)

### 方法5：CoordAtt + ECA 组合注意力

- **结构**：Backbone 嵌入 CoordAtt（空间坐标注意力） + Neck 嵌入 ECA（通道注意力）
- **原理**：CoordAtt 将二维池化分解为 X/Y 一维编码 → 保留"特征在哪"的位置信息
- **设计思路**：Backbone 阶段增强空间定位(where) + Neck 阶段增强通道判别(what)
- **定位**：验证"空间+通道双维度注意力"在课堂场景下的效果上限
- **v2 关键改进**：初版实验（m_pretrained, 100 epochs）使用完整强增强（Mosaic 0.8, MixUp 0.1），mAP@0.5 仅 84.59%，未超过基线。分析发现 CoordAtt 依赖 X/Y 空间位置信息生成注意力权重，而 Mosaic 和 MixUp 破坏了真实空间坐标关系。v2 版本（coordatt_backbone_eca_neck_v2）针对性调整增强策略——关闭 Mosaic/MixUp/Copy-Paste（均=0），降低旋转至 3.0°、平移至 0.05、缩放至 0.15——并缩短训练至 60 轮。v2 在测试集上取得 mAP@0.5=**96.25%**、mAP@0.5:0.95=**78.49%**、Precision=93.92%、Recall=92.04%，**mAP@0.5 较 Baseline(800) 提升 6.32 个百分点**，综合性能仅次于 Strong。
- **选择原因**：方法2的纯通道注意力失败，因为 ECA 完全不感知空间位置。但举手（手在哪？举多高？）、低头（头相对于身体在哪？）恰恰强依赖空间关系；CoordAtt 将 X/Y 方向分开编码后再融合，兼顾"哪个通道重要"和"重要特征在图像的哪里"。v2 的成功还揭示了一个重要原则：**注意力机制的效果不仅取决于模块结构，更取决于训练策略（尤其是数据增强）是否与注意力机制的特性相匹配**。

![CoordAtt+ECA混淆矩阵](论文图表/六模型混淆矩阵/05_CoordAtt_ECA_confusion_matrix_normalized.png)

### 方法6：Strong 最终高精度模型

- **结构**：标准 YOLOv8m，**零参数增量，完全不改网络**
- **数据**：长尾均衡训练集（低头/趴桌过采样 +175%）
- **训练**：baseline best.pt → imgsz=800, cls=0.65, lr=1×10⁻⁴, cos_lr, 60 轮
- **增强**：关闭全部强增强，仅保留弱 HSV + 轻量几何 + 水平翻转
- **核心**：四项策略融合 — 长尾均衡 × 800分辨率 × 弱增强 × 二阶段微调
- **选择原因**：方法1~5的经验收敛——数据（长尾均衡解决少数类漏检）→ 输入（800分辨率保留小目标细节）→ 增强（弱增强保护姿态语义）→ 训练（二阶段+低lr+余弦退火实现渐进收敛），四个维度同时发力才能产生协同增益

![Strong混淆矩阵](论文图表/六模型混淆矩阵/06_Strong_Final_confusion_matrix_normalized.png)

> **探索路径**：方法1建基线 → 方法2/3试结构改进（ECA和P2未超基线）→ 方法5初版失败（强增强破坏CoordAtt空间信息）→ 方法4试训练策略（有苗头）→ 方法5 v2转向弱增强（CoordAtt+ECA成功，mAP@0.5=96.25%）→ 方法6四策略融合（最优，mAP@0.5=96.73%）

## 2. 课堂专注度计算算法

**设计思路**：将检测结果（边界框+类别+置信度）转化为课堂专注度评分（0~10），比单纯输出检测框更有教学应用价值。

![专注度流程](论文图表/图5-2_课堂专注度计算流程图.png)

### 2.1 静态专注度（单张图片）

```
班级专注度 = Σ(各目标基础分 × 置信度) / 检测人数
```

**行为→基础分映射**（`calculate_single_focus`）：

| 行为 | 基础分 | 依据 |
|------|:---:|------|
| 举手 hand-raising | 8.5 | 主动参与课堂互动 |
| 阅读 reading | 8.5 | 正常学习行为 |
| 书写 writing | 8.5 | 正常学习行为 |
| 低头 bowing the head | 5.0 | 专注度不确定，中等分值 |
| 趴桌 leaning over table | 2.0 | 明显低专注状态 |
| 使用手机 using phone | 2.0 | 明显低专注状态 |

### 2.2 动态专注度（视频流 FocusTracker）

单帧检测易受误检、遮挡影响 → 引入时序稳定性跟踪。

**四步计算流程**：

```
算法 FocusTracker:Compute(boxes, classes, confidences)

Step 1 — 基础分（置信度加权）
  for i in 1..N:
    base_score[i] = 行为基础分 × confidences[i]

Step 2 — IoU 匹配（关联历史目标）
  for each 当前检测框:
    在已记录学生中找 IoU > 0.3 的最大匹配
    匹配成功 → 追加到该生历史分数列表（保留最近 N=10 帧）
    匹配失败 → 创建新学生 ID

Step 3 — 时序惩罚（持续低专注加重扣分）
  for each 学生:
    取最近 K=5 帧，统计 < 4.0 的帧数
    超过阈值 → penalty = min(2.0, 超额×0.3)
    final = max(0, 最新分数 - penalty)

Step 4 — 趋势调整（班级整体趋势修正）
  对最近 5 帧班级平均值做线性回归
  上升趋势 → 加分（最多 +1.0×10）
  下降趋势 → 减分（最多 -1.0×10）
  最终输出裁剪到 [0, 10]
```

**FocusTracker 关键参数**：

| 参数 | 值 | 含义 |
|------|:---:|------|
| RECENT_FRAMES | 10 | 每学生保留最近 N 帧历史 |
| PERSIST_THRESHOLD | 5 | 连续低专注惩罚窗口大小 |
| PERSIST_PENALTY | 0.3 | 每帧超额惩罚系数 |
| TREND_WEIGHT | 10 | 趋势调整权重 |
| IoU 匹配阈值 | 0.3 | 判断是否同一学生 |

## 2. 消融实验

### 2.1 训练策略消融（Strong 模型）

| 策略组合 | mAP@0.5 | mAP@0.5:0.95 | 变化 |
|------|:---:|:---:|:---:|
| Baseline(800) | 89.93% | 72.97% | — |
| +800分辨率+弱增强+二阶段微调(方法4) | 90.54% | 76.34% | +3.37 |
| +长尾均衡+800+弱增强+二阶段(方法6) | **96.73%** | **82.40%** | **+9.43** |

> 长尾均衡是 Strong 模型超越 baseline 的关键增量因素；四项策略存在显著协同增益。

### 2.2 注意力机制消融（CoordAtt+ECA v2）

| 实验配置 | mAP@0.5 | mAP@0.5:0.95 | Δ vs Baseline(800) |
|------|:---:|:---:|:---:|
| Baseline(800) | 89.93% | 72.97% | — |
| ECA 单通道注意力(方法2) | 83.53% | 65.34% | −6.40% |
| CoordAtt+ECA 初版(强增强, 100 epoch) | 84.59% | 65.59% | −5.34% |
| CoordAtt+ECA v2(弱增强, 60 epoch) | **96.25%** | **78.49%** | **+6.32%** |

> 三组消融揭示了清晰的因果关系：(1) ECA 单通道注意力反而损害性能，因为仅关注"哪些通道重要"而丢失空间位置信息；(2) CoordAtt+ECA 初版同样失败，因为 Mosaic 和 MixUp 破坏了 CoordAtt 依赖的 X/Y 空间坐标关系；(3) v2 仅调整增强策略（关闭强增强、降低几何扰动），mAP@0.5 即从 84.59% 飙升至 96.25%（+11.66 个百分点），证明了**注意力机制的效果高度依赖训练策略与注意力特性之间的匹配**。

## 4. 论文总结

本文设计并实现了一套基于YOLOv8的学生课堂行为检测系统，完成数据集配置、六种策略对比实验、系统开发和结果分析。系统能够识别举手、阅读、书写、使用手机、低头、趴桌六类行为，支持图片、视频、摄像头和批量检测。

在算法实验方面，本文以YOLOv8m基线模型（mAP@0.5=89.61%）为起点，依次开展五组改进实验。ECA单通道注意力和P2检测头两种纯结构改进均未超过基线。CoordAtt+ECA组合注意力方案在匹配弱增强策略后取得mAP@0.5=96.25%的显著提升，验证了空间-通道互补注意力设计的有效性，同时揭示了注意力机制效果高度依赖训练策略匹配这一核心原则。Strong模型进一步融合长尾均衡训练、800高分辨率、弱增强和二阶段微调四项策略，取得mAP@0.5=96.73%、mAP@0.5:0.95=82.40%的最优结果。本文将Strong作为高精度推荐方案，将Baseline作为轻量实时备选方案。

本文创新点体现在三个方面：(1) 面向课堂行为检测构建了从基线训练到六策略对比的完整实验体系，分析了不同改进方向的实际效果；(2) 将目标检测与课堂专注度计算结合，设计了基于行为类别权重、置信度融合和时序跟踪的专注度评估方法；(3) 基于PyQt5+OpenCV完成桌面端可视化系统开发，实现了从模型推理到专注度分析的完整交互流程。

## 5. 工作展望

**数据与算法层面**：当前数据集类别分布不均衡，低头和趴桌样本较少，少数类识别仍有提升空间。专注度计算基于规则设计，后续可结合人工评分训练更客观的评估模型。此外可引入人体姿态估计、目标跟踪和多摄像头融合技术，提升复杂遮挡场景下的识别能力。

**工程部署层面**：当前系统为本地桌面端原型，后续可将模型导出为ONNX或TensorRT格式加速推理，开发Web端应用支持多用户访问，或采用边缘计算方案在教室本地完成推理、仅上传统计结果以保护隐私。系统可增加数据库模块，长期记录课堂状态数据，为教学研究提供数据支撑。

**功能扩展层面**：可增加结果导出（CSV/Excel）、专注度曲线绘制、类别占比可视化和检测结果筛选等功能，使统计分析更直观。视频检测可引入ByteTrack/DeepSORT等跟踪算法，关联同一学生在连续帧中的行为变化，减少单帧误检对专注度曲线的干扰。
